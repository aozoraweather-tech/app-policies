# App Policies

自作アプリのプライバシーポリシーを公開するためのリポジトリです。

## 公開ページ

- [ヒマッチ プライバシーポリシー](./himatch-privacy-policy.md)
- [まちあわせ駅 プライバシーポリシー](./machiawase-eki-privacy-policy.md)

GitHub Pagesで公開しており、各アプリのApp Store Connectの「プライバシーポリシーURL」欄にはGitHub Pages上の各ページのURLを登録しています。

## 構成

このリポジトリにはアプリのソースコードは含まれません。プライバシーポリシーの文書のみを管理します。
